# The files the game template owns, for `preffect-dev sync-template`. The sync reads the template's copy of
# this list, so a file the template starts owning later reaches games too. preffect-home's
# images/dev-base/preffect-sync-template has the full rules, and the format line says which version of them.
#
#   owned <path>      the template's file, which games don't edit. Replaced when a game hasn't changed it.
#   shared <path>     games edit or extend it, so the sync lists it for a merge by hand when the template changes it
#   retired <path>    never belongs in a game: deleted if present
#   render <script>   rewrites the template's names and ports to the game's, then formats with the game's prettier.
#                     It's template-only, so it's also retired.
#   after <script>    runs once a sync has changed files
#
# scripts/presetup.test.sh checks that every agent definition is owned, its old role file retired, and every
# listed file exists. A game's README.md isn't here: it starts as README.game.md and is the game's own.
